# Sweet Drop Kitchen

A mobile-first preorder landing page template for local food sellers, popup dessert brands, and Instagram-first preorder businesses.

Built for businesses that:
- announce weekly drops
- coordinate orders through Instagram DMs
- offer local pickup
- need something cleaner than scattered story posts and manual DMs

---

## Overview

Sweet Drop Kitchen is a lightweight static website template focused on improving preorder flow and reducing friction for small local food businesses.

Instead of forcing customers to piece together:
- menus
- pricing
- pickup dates
- preorder deadlines
- payment methods
- Instagram messages

…the site centralizes everything into a single mobile-first experience.

The template includes:
- product menu cards
- pickup date/drop cards
- preorder message builder
- Instagram DM flow
- pickup time selection
- responsive mobile UI
- editable configuration data

No checkout system required.
